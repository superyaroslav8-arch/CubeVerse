# CubeVerse 🎲

**CubeVerse** — простая веб-платформа игр в стиле Roblox.

Много разных мини-игр, всё работает прямо в браузере. Ничего устанавливать!

## Как запустить

1. Открой [GitHub Pages](https://superyaroslav8-arch.github.io/CubeVerse/) (после включения в Settings → Pages)
2. Или просто открой `index.html` локально

## Игры

- **Obby Adventure** — пройди препятствия
- **Click Tycoon** — заработай монеты и прокачивай
- **Speed Race** — гонки
- **Hangout Plaza** — гуляй с друзьями (локально)
- **Pet Simulator** — собирай питомцев
