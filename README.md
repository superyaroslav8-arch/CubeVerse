# Нексус (Nexus)

**Нексус** — полноценная веб-платформа игр в стиле Roblox.

- Каталог игр
- Создание и публикация своих игр
- Аватар, настройки, друзья
- Всё работает в браузере, всё на русском

Открой: https://superyaroslav8-arch.github.io/CubeVerse/
