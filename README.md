# Кибер-склад

Финальная версия игровой платформы.

## Что есть
- 16 игр (паркур, аркады, спорт, кликеры)
- Футбол, Хоккей, Баскетбол, Теннис
- Вход и регистрация
- Сохранение рекордов и прогресса
- Красивый адаптивный дизайн
- Всё на русском
